# Практическое занятие 1: Репозитории и интеграции

Учебный проект по теме репозиториев, веток и REST API.

В проекте есть ноутбук `rest_api_demo.ipynb`, который обращается к OMDb API, получает JSON с информацией о фильме и выводит основные поля: название, год, жанр, режиссёра, актёров и рейтинг IMDb.

## Что сделано

- создан проект для лабораторной работы;
- добавлен пример REST API на Python;
- подготовлен вариант с ручным вводом API-ключа;
- создана и влита ветка `movie-output-feature`;
- создана отдельная ветка `env-feature` для варианта с `.env`;
- `.env` добавлен в `.gitignore`, чтобы секреты не попали в репозиторий;
- добавлена обработка ошибки, если фильм не найден.

## Запуск базового варианта

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Открыть `rest_api_demo.ipynb`.
3. Запустить ячейки по порядку.
4. Ввести название фильма и OMDb API key.

## Ветка env-feature

В ветке `env-feature` API-ключ читается из файла `.env`.

Создайте файл `.env` по примеру:

```env
OMDB_API_KEY=ваш_ключ
```

Файл `.env` не коммитится в Git.
